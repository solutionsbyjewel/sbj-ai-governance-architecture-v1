## Architecture Scope

V1.0 defines ten governance dimensions:

1. Generation
2. Assistance
3. Agency
4. Autonomy
5. Environmental Interaction
6. Physical Actuation
7. Authority
8. Evidence
9. Accountability
10. Continuous Control

The architecture also includes cross-cutting governance constructs for system state, bounded authority, governed transitions, execution traceability, downstream authority, evidence preservation, and continuous authorization.

## Operational Authorization Sequence

`IDENTITY → GOAL → CAPABILITY → AUTHORITY → PERMISSION → ENVIRONMENT → ACTION → OBSERVATION → EVIDENCE → ACCOUNTABILITY → CONTINUOUS CONTROL`
